
### <div align="center">Full-Stack & Mobile Developer | Computer Engineering Student</div>  
  

I am a Computer Engineering student and software developer focused on building modern web and mobile applications using React, Next.js, React Native (Expo), TypeScript, and NestJS. Currently, I am actively developing **Vestiy**, an AI-powered wardrobe catalog and outfit recommendation app, alongside an interactive web portal for the INOVA Engineering and Innovation Community. I also developed and deployed **yazokuluvarmi.com**, a university summer school portal created as part of a TÜBİTAK 2209-A research project.

Beyond web and mobile development, I am deeply interested in hardware systems, embedded engineering, and local AI solutions. I build custom F450 quadcopter drones using Pixhawk and APM flight controllers, run local LLMs through Ollama, and continue to expand my knowledge in Three.js, real-time object detection, and Vision LLM integrations. Feel free to reach out if you would like to discuss modern JavaScript/TypeScript stacks, backend architecture with C# or NestJS, or hardware and AI integration projects.
